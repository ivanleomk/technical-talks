## Product Purpose

"Building Agents with the Managed Agents API" — a code-heavy workshop that
walks builders from an API key to the Interactions API to a local agent loop
to managed agents, so they can follow the live demos and leave knowing which
layer to reach for.

## Operating Context

The deck is presented live alongside code demos. Slides are orientation and
backup; the speaker and the snippets carry the detail.

## Capabilities and Constraints

- Vite, React, and MDX presentation with one numbered file per slide.
- Flow: intro → rough agenda (section names only, no detail) → API key via
  AI Studio → two AI Studio demos (lighthouse-boat, Sheets+Gmail site) →
  Interactions API → Building an agent → Managed Agents → questions.
- Each part lands one line; demo slides list the snippets being run.
