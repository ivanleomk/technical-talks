# Partner pitches (Live stack)

Partners don’t resell a different model — they sell the hard part around Live.

| Partner | Sell |
|---------|------|
| Pipecat | Production voice agents; telephony/WebRTC; async tools UX |
| LangChain / LangSmith | Trace S2S + Deep Agents harness under continuous speech |
| LiveKit | Room + Agents; BYOK or Inference |
| Vercel AI Gateway | AI SDK realtime; short-lived tokens; background tools |
| Vision Agents | Voice + camera/screenshare (~18-line agent) |
| Fishjam / Agora | Media plane ↔ Gemini WebSocket |

**Line:** Google = async tools while audio flows; Pipecat/Vercel = ship on phone/web; LangChain = prove it in traces.
