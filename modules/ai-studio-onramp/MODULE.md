# AI Studio on-ramp

**Point:** everything in this talk runs on the free tier at aistudio.google.com — start in the browser, ship an app, and even run on-device.

## Beats
1. **Playground, multimodal** — prompt with text, image, audio, video in one place.
2. **Build** (Lovable-style) — full deployable app from natural language.
   - Boat game from a single prompt, then iterate conversationally.
   - Attendee email workflow: Google Sheets → personalised emails via native Workspace integrations.
3. **On-device Gemma** — Gemma 4 (4B params, ~1 GB RAM per talk notes) powering transcription inside AI Studio; no server round-trip.
