# technical-talks

Mix-and-match content library for Ivan’s technical talks.

## How to use
1. **Modules** are reusable beats (pricing, partner pitches, Interaction snippets, Live async tools, Antigravity skills, Managed Agents, CLI).
2. **Talks** are assemblies — a 30‑min outline that pulls modules by id.
3. Ask the **Deck** bot to propose a talk from modules, or to split a new talk into modules.

## Layout
```
modules/          # atomic content units
talks/            # full talk outlines (compose modules)
assets/           # shared diagrams, screenshots
bots/             # Deck bot brief (persona mirror)
```
